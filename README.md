# Python Data Analysis Learning Journey

This repository contains notebooks from my personal practice and Python classes as I develop my skills for data analysis.

## Learning topics covered

### 1. Python fundamentals
From `01-python-fundamentals/Personal_Python_Class.ipynb`:
- Variables and basic data types
- Printing output and collecting user input
- Type conversion using `int()` and `float()`
- Arithmetic operators
- Conditional statements: `if`, `elif`, and `else`

### 2. NumPy, Pandas and working with tabular data
From `02-numpy-pandas-and-dataframes/Basics_Python_Class.ipynb`:
- NumPy arrays
- Pandas Series
- Creating and accessing Series values
- Creating DataFrames from arrays and dictionaries
- Adding rows and columns
- Exporting data to CSV

### 3. Visualisation and introductory predictive modelling
Also covered in the Basics Python Class notebook:
- Creating scatter plots with Matplotlib
- Using scikit-learn's `LinearRegression`
- Fitting a simple regression model
- Plotting a regression line
- Generating a basic prediction from a new input
